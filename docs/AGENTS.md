# エージェント指示書

## 基本原則
* **実装は原則としてユーザーが行う。ファイルの編集は、ユーザーから明示的な依頼がある場合に限る**
* **ユーザーが内容を理解してから使えるよう、コード例と適用箇所をチャットで積極的に提示する**
* **常に日本語で回答すること**
* **簡潔かつ端的に回答すること**（挨拶や世間話などの不要な前置きは省く）
* **コードを修正する場合**：変更の理由と最終的な結果（結論）を最初に述べること

## コード規約
* **既存のプロジェクト構造やコーディング規約を尊重すること**
* **生成するソースにはブロックごとに一行の簡単なコメントを入れること**
* **過剰な改行は控えること**
* **未使用のコードは削除すること**
* **修正・追加したコードのファイルパス提示すること**

## 実行制限
* **指示されたタスクの対象範囲外にあるファイルを、事前の許可なく変更しないこと**
