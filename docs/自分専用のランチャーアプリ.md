# 自分専用のランチャーアプリ

デスクトップのショートカットをまとめ、自分好みに使えるWindows向けランチャー。

## 現在の仕様

- 画面は左約30％のショートカット一覧と、右約70％のメイン領域に分かれる。一覧には保存済みの項目名を表示する。
- `.lnk` と `.url` をドラッグ＆ドロップで登録する。管理フォルダーにコピーし、元のファイル名から表示名を設定する。
- 一覧の項目をダブルクリックすると、保存したコピーをWindows経由で開く。`.lnk` に保存された引数や作業フォルダーも利用できる。起動先が移動・削除されるとリンク切れが起こり得る。
- 右クリックメニューの `Rename` は1件選択時に使える。表示名を変更すると一覧と `launcher.json` に反映される。
- `Delete` は1件または複数件に対応する。Ctrl／Shiftで選択し、確認後に登録情報と管理フォルダー内のコピーを削除する。取り込み元のファイルはそのまま残る。

## 今後の展望

- 右側のメイン領域に、ユーザーが選んだ画像を背景として設定できるようにする。
- 背景の上にショートカットのアイコンと名前を自由に配置し、位置を保存して次回起動時に復元する。アイコンのダブルクリックで、一覧と同じショートカットを起動する。
- 左側の一覧を折りたたんで隠し、必要なときに再表示できるようにする。
- ショートカット本来のアイコンの表示や、任意のアイコン画像への変更に対応する。デスクトップの右クリックメニューの完全再現は対象外とする。

### 自由配置の方針

- グリッドに吸着させず、空いている位置に自由に配置できる。
- アイコンと名前を含む項目全体を一つの矩形として扱う。項目同士は辺が接してもよいが、内側の領域は重ねない。
- 移動やサイズ変更を確定するときに別の項目と重なっていたら、操作前の位置とサイズに戻す。新規登録した項目も、他の項目と重ならない位置に置く。

## ショートカットのデータの持ち方

ユーザーごとの `%LOCALAPPDATA%\MyLauncher` に `launcher.json` を置く。登録情報を `entries` 配列にまとめ、形式の変更に備えて `schemaVersion` を持たせる。取り込んだショートカットは `shortcuts/` に保存する。任意のアイコン画像に対応する際は、選んだ画像を `icons/` にコピーする予定。

| 項目 | 内容 |
| --- | --- |
| `id` | 登録ごとに発行する固定のID。名前やリンク先を変更しても同じ項目として扱う。 |
| `name` | 画面に表示する名前。初期値は元のショートカット名で、後から変更できる。 |
| `target` | 起動先の種類と参照先。取り込んだ `.lnk`／`.url` は、保存したコピーの相対パスを記録する。将来、直接登録を追加する場合はファイルパスやURLを種類ごとに持てる。 |
| `registeredAt` | 最初に登録した日時。JSONにはUTCのISO 8601形式で保存し、画面では必要に応じてローカル時刻で表示する。 |
| `layout` | アイコンと名前を含む項目の位置 `x`・`y` と、横幅 `width`・縦幅 `height`。現在は初期値を保存している。自由配置では配置面の左上を基準とし、単位はWPFのデバイス非依存ピクセルとする。 |
| `icon` | アイコンの選び方。現在は初期値の `auto` を保存している。今後は `auto` で元のアイコンを表示し、`template` で組み込みアイコンのID、`image` で保存した画像の相対パスを扱う予定。 |

```json
{
  "schemaVersion": 1,
  "entries": [
    {
      "id": "84cb04bc-c24e-4203-a703-fd69469a8fba",
      "name": "ゲーム",
      "target": {
        "type": "shortcut",
        "path": "shortcuts/84cb04bc-c24e-4203-a703-fd69469a8fba/ゲーム.lnk"
      },
      "registeredAt": "2026-11-19T07:30:00Z",
      "layout": { "x": 0, "y": 0, "width": 112, "height": 96 },
      "icon": { "type": "auto" }
    }
  ]
}
```

## ランチャー設定（案）

ランチャー全体の設定は、`launcher.json` のトップレベルに `settings` として保存する。起動時に読み込み、項目が未設定の場合はアプリの既定値を適用する。

| 項目 | 内容 |
| --- | --- |
| `theme` | `system`（Windowsの設定に合わせる）、`light`、`dark`。初期値は `system` とする。 |
| `background` | `default`（標準の背景）、`template`（組み込み背景のID）、`image`（ユーザー画像の相対パス）。ユーザー画像はアプリのデータフォルダーの `backgrounds/` にコピーする。 |
| `window` | 通常時の横幅 `width` と縦幅 `height` をWPFのデバイス非依存ピクセルで保存する。最大化で閉じた場合に復元できるよう、`isMaximized` も別に記録する。 |

```json
{
  "settings": {
    "theme": "system",
    "background": { "type": "image", "path": "backgrounds/room.jpg" },
    "window": { "width": 1200, "height": 900, "isMaximized": false }
  }
}
```

## 技術構成

- 開発言語：C#（.NET）
- UI：WPF／XAML
- 設定保存：JSONファイル
- 登録したショートカット：アプリのデータフォルダーに保存
- サーバー・データベースは使用しない。
